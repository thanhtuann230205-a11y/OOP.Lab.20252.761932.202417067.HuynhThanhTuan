Lab 05 GUI Programming

1. Swing and AWT comparison
- AWT top-level container: Frame. Swing top-level container: JFrame.
- AWT components are heavyweight, for example Label and TextField. Swing components are lightweight, for example JLabel and JTextField.
- Swing components should be added to the JFrame content pane, while AWT components can be added directly to Frame.
- Event handling is similar in both libraries: components register listeners and listeners implement callback methods such as actionPerformed().
